# 🔊 Sound Booster

> **오디오의 모든 힘을 끌어내세요.** 볼륨을 높이고 선명도를 개선하며 모든 탭을 콘서트홀로 바꿔주는 가벼운 브라우저 확장 프로그램입니다.

## ✨ 기능

- 🚀 **즉각적인 볼륨 부스트** — 모든 탭의 오디오를 기본 한도를 훨씬 넘어 증폭합니다.
- 🎚️ **정밀 제어** — 부드러운 실시간 슬라이더로 게인을 미세 조정합니다.
- 🎧 **크리스탈처럼 맑은 사운드** — 왜곡을 줄이고 높은 볼륨에서도 깨끗한 오디오를 유지합니다.
- 🌐 **어디서나 작동** — YouTube, Spotify, Twitch, 게임, 팟캐스트에 완벽합니다.
- ⚡ **가볍고 빠름** — 불필요한 요소 없음, 최소 CPU 사용, 즉각적인 반응.
- 🔒 **프라이버시 우선** — 추적 없음, 분석 없음, 데이터는 브라우저를 벗어나지 않습니다.
