> **释放你音频的全部力量。** 一款轻量级浏览器扩展，提升音量、增强清晰度，让每个标签页都变成音乐厅。

## ✨ 功能

- 🚀 **即时音量提升** — 将任意标签页的音频放大到远超默认上限。
- 🎚️ **精确控制** — 使用流畅的实时滑块微调增益。
- 🎧 **晶莹剔透的音质** — 减少失真，在高音量下保持音频清晰。
- 🌐 **随处可用** — 完美适用于 YouTube、Spotify、Twitch、游戏和播客。
- ⚡ **轻量快速** — 无冗余，极低 CPU 占用，即时响应。
- 🔒 **隐私优先** — 无跟踪、无分析，数据绝不离开你的浏览器。
