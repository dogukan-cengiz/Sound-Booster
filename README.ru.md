# 🔊 Sound Booster

> **Раскройте всю мощь вашего звука.** Лёгкое расширение для браузера, которое повышает громкость, улучшает чёткость и превращает каждую вкладку в концертный зал.

## ✨ Возможности

- 🚀 **Мгновенное усиление громкости** — Усиливайте звук любой вкладки далеко за пределы стандартного лимита.
- 🎚️ **Точный контроль** — Настраивайте усиление плавным ползунком в реальном времени.
- 🎧 **Кристально чистый звук** — Снижайте искажения и сохраняйте чистоту на высоких уровнях.
- 🌐 **Работает везде** — Идеально для YouTube, Spotify, Twitch, игр и подкастов.
- ⚡ **Лёгкий и быстрый** — Без лишнего, минимальная нагрузка на CPU, мгновенный отклик.
- 🔒 **Приватность прежде всего** — Без отслеживания, без аналитики, данные не покидают ваш браузер.
